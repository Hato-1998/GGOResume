개요

GAS 기반 전투와 캐릭터 성장, 스킬 메뉴, 체크포인트 저장을 연결한 탑다운 RPG입니다. Stephen Ulibarri의 Unreal Engine 5 - Gameplay Ability System - Top Down RPG 강의를 기반으로 학습하고, 저장·데이터·입력의 책임을 서브시스템과 컴포넌트로 분리했습니다.

설계 과제

01. 전투 상태와 실행 주체 분리

과제 캐릭터의 행동과 지속되는 플레이어 상태를 구분하고, 피해 계산에서 UI까지 흐름을 연결해야 합니다.

설계 ASC·AttributeSet은 PlayerState에 두고 Character를 행동 주체로 연결합니다. GameplayAbility 실행, GameplayEffect·ExecCalc 계산, AttributeSet 반영으로 역할을 나눕니다.

설계 상세 읽기 →

02. 입력과 화면의 책임 분리

과제 클릭 이동과 스킬이 마우스 입력을 공유하고, PlayerController에 기능이 모이기 쉽습니다.

설계 클릭 이동·커서 대상·마법진·피해 숫자를 컴포넌트로 분리합니다. 전투 HUD와 성장 메뉴는 WidgetController, 로드 화면은 MVVM으로 구성합니다.

설계 상세 읽기 →

03. 맵별 진행 상태 복원

과제 맵을 이동해도 슬롯·플레이어·배치 액터 상태를 일관된 기준으로 저장해야 합니다.

설계 SaveGameSubsystem이 저장 흐름을 담당합니다. 액터를 영속 GUID로 식별하고 이전 저장의 이름 매칭을 보조 경로로 유지하며, 맵별 상태를 기존 월드 액터에 복원합니다.

설계 전제

  • 스킬 실행은 GameplayAbility, 수치 변화는 GameplayEffect·AttributeSet을 중심으로 구성합니다.
  • 캐릭터 기본값·스킬 정보·레벨별 계수는 DataAsset과 테이블로 관리합니다.
  • HUD와 로드 화면은 목적에 맞춰 WidgetController와 MVVM을 각각 사용합니다.
  • 현재 저장 경로는 동기 방식이며 기존 배치 액터의 상태를 복원합니다. 비동기 저장 큐나 일반적인 동적 액터 재생성 시스템으로 설명하지 않습니다.

구조 한눈에 보기

  1. 입력 의도Enhanced Input·GameplayTag를 PlayerController에서 조정
  2. 전투·속성PlayerState의 ASC를 거쳐 스킬·효과·피해 계산 수행
  3. 화면 반영AttributeSet 변경을 WidgetController가 HUD와 성장 메뉴에 전달
  4. 진행 저장체크포인트·로드 화면이 SaveGameSubsystem을 통해 슬롯과 맵별 상태 관리
